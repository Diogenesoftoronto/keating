The call stack

Where paused calls wait, and why the last one in is the first one out.

By the endDraw the stack for a three-deep callSay which call returns first

Each time a function calls another, the caller is set aside with everything it knew. The place those set-aside calls wait is the call stack.

You already predicted that countdown(2) prints its after lines backwards. The stack is the reason: the most recent call is on top, and only the top can finish.

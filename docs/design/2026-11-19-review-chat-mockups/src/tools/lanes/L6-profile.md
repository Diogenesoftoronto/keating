1. 2. Editor (left) as one stack of collapsible section cards in the PAGE'S order: About, Learning now, Topics, Shared work, Next steps, Links (the reorderable ones), then "Look and layout". This replaces the separate "Sections: tick to show, use the arrows to reorder" list; the stored order and visibility fields stay the same. One card open at a time by default; opening a card focuses its first field. All existing fields, limits, counters, helper text, add/remove/move controls and the shared-session picker stay, inside their cards. Look and layout: accent colour as swatches with visible names on hover/focus and as text for screen readers, layout as a kit `Segmented` control, and the saved-session count as a toggle chip with its existing unavailable state.
3. Hidden means not published: when a section is hidden, its content must not be written to the published record. Today hidden sections vanish from the page but their text is still sent to the learner's data server. Change the publish projection so hidden sections' fields are omitted from the record (the local draft still keeps them so unhiding restores them), make "has something to publish" count only visible content, and label a hidden card "hidden: not shown, not published". Add tests proving a hidden section's text is absent from the outgoing record and returns when unhidden, and that reading older records still works.
4. Preview (right): the real `PublicProfileView` inside a page frame with the eyebrow "Preview: what visitors will see", passing the same handle and date the public page would show so the preview matches it. At narrow widths keep the existing Edit / Preview tabs (kit `Tabs`) and fix the empty-preview sentence so it does not say "on the left" when the panes are stacked.
5. Secondary actions as quiet links under the editor: "Make private" (keep its explanation and confirmation of what remains elsewhere), "Discard my edits" / "Clear the form", "Reload status", and the public link with "Copy link" (show "Copying was blocked" style feedback if the clipboard write fails, which today is silent).

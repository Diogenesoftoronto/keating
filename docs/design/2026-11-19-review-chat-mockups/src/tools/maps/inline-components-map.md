**Shared audit baselines used in the rows.**

- **Shared panel** (`SR:45–71`): 1px `--border`, .75rem radius, `--background`, 1rem padding, no shadow. Title 1rem/700 and description .8125rem muted. Child section uses a top rule. Local Panda `button/input/badge/reviewRow` helpers use .5rem radii, .8125rem action text and small muted tags (.6875rem); the buttons have visible focus. Colors adapt by token. The panel grid has no explicit max width or motion of its own. Document validity and submission authority control disabled/read-only state and can surface “Retry interaction” in a status region.
- **Activity** (`web/src/keating/openui/activity.css:1–74`): an inner shrinkable single-track grid that inherits the chat font (visibly mono in the seeded turns) with compact metadata and 1.3rem prompts, separately styled controls, hover/entry feedback, focus rings, and OS reduced-motion overrides. The thread caps it earlier. On phones the same nav still runs across the available width, with an extra rule at 380px. Each row below calls out its overrides and controls. Shared panel and Activity can coexist, so one lesson can show two competing hierarchies.
- **Task** (`SR:748–940`): shared panel, then a top-rule section and nested outlined .5rem checklist rows; badge/criteria .6875–.75rem, body/criteria .8125rem, with prose inheriting chat serif where the selector reaches. Uses local `input`, `shared-task__submit`, native checkboxes, `SubmissionAttachments`, `SaveTaskToCourse`, `PrintAssignmentButton` and optional capture. Token colors, no chart and no dedicated animation in the brief. Native form labels, status/alert, wrap on receipt. Base adds upload, saving, disabled, retry/error, submitted receipt “Saved on this device,” optional due/open scheduling and prior rounds. The closed window disables submission and identifies when it opens. Subtypes can omit submission entirely.
- **Plain anchored** means an inline rule, disclosure or bare text region with token colors and no dedicated chart, elevation or entrance motion. It can still need the correct type, labels and focus treatment.

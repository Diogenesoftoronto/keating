## 1. Getting learner data out

### Session review ZIP · /review/sessions/$sessionId

- Review workspace toolbar **Export**, with text hidden below sm, and review desk icon **Export review** (accessible label changes to **Exporting review**). Toolbar status is “Preparing export...” or “Saving changes...” when saving takes precedence. Click saves a dirty review draft first, then downloads directly. There is no dialog, format selector, scope control, consent prompt or success message. Errors surface from save/export, including “The trajectory review has not loaded yet.” (`src/components/trajectory/TrajectoryReviewWorkspace.tsx:242–243`, `ReviewDesk.tsx:303–307` in the same directory, `src/pages/TrajectoryReview.tsx:275,435–445`, `src/hooks/use-trajectory-review.ts:354–380`.)
- `keating-trajectory-review-<ISO timestamp with colons and dots replaced by hyphens>.zip`. Contents are `manifest.json`, `README.md`, `data/reviews/trajectory-reviews.jsonl`, `data/sft/review-corrections.{chatml,alpaca}.jsonl`, `data/preferences/review.{dpo.chat,dpo.text,kto}.jsonl`, and `data/artifacts/review-revisions.jsonl`. If available, also `data/judgement/{turn-judgements,human-labels}.jsonl` and `data/hindsight/turns.jsonl`. Training derivatives require a final review and completed, selected, preferred candidates, plus reconstructable preceding context for response corrections. (`src/keating/trajectory-export.ts:129–138,470–652`.)
- Privacy is in the archive README: “Secret-shaped values are replaced with `[REDACTED]` in every data file using Keating's security redaction helper. (`src/keating/trajectory-export.ts:433–498`.)

## Vocabulary and rough edges

- **Export** can mean a single-session review ZIP, standalone sandbox JSON, Anki package, trace, or leaderboard. **Portable** covers browser migration JSON and server-backed shared links; **snapshot** covers embedded public URLs and local sandbox state. **Share** can mean publish publicly or create a local-only link. **Download PDF** can mean print or fetch an existing PDF. (Controls cited above.)
- Sandbox code/history appears both in Sandbox History **Export** and in Usage **Export portable JSON** under **Include sandbox code history**. Usage swallows sandbox export failure and still reports session/feedback success. Decks can be exported as materials JSON and as Anki or TSV. (`src/keating/portable-data.ts:88–94`, `src/pages/Usage.tsx:145`, `src/components/ArtifactViewer.tsx:174–175`, `src/pages/ComingUp.tsx:519–538`.)
- Review export saves dirty changes and downloads without an inclusion preview. Its privacy explanation is inside the ZIP, and judgement-data reads can fail silently. Both Usage transfer labels and Coming up export labels stay fixed during work. **Link copied** can be used when clipboard permission prevented copying. (`src/pages/TrajectoryReview.tsx:435–445`, `src/hooks/use-trajectory-review.ts:361–370`, `src/pages/Usage.tsx:217–232`, `src/pages/ComingUp.tsx:610–614`, `src/pages/chat/ChatHeader.tsx:412–416`, `src/pages/chat/session-sharing.ts:50`.)

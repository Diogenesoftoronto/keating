Outcome
A learner signal from 0 to 100: thumbs, confusion, and graded quizzes.
PROSPER
A weighted mix of seven dimensions. Mostly keyword patterns, so treat it as a rough ordering.
Not built
Sending the same learner moment to every model for a like-for-like comparison.

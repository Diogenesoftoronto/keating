Which call finishes first?

Each call to countdown pauses while the next one runs. Follow the stack to the base case, then trace the returns.

Python
def countdown(n: int) -> None:
    if n <= 0:
        return
    countdown(n - 1)
Quick check

countdown(1) resumes first. Once it finishes, countdown(2) can resume.

Tutor · Selected passage

Each paused call sits on a stack, and the most recent one finishes first.

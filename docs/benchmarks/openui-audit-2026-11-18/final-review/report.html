Does the learner get the interface the tutor wrote?

November 18, 2026. We found two cases where the tutor wrote a usable prediction field and Keating showed the learner a prose question. Both decision models also helped tutors write better replies on some of the same learner prompts. The evidence supports keeping decision guidance and changing how Keating chooses among drafts. Try the original replies · View the classroom demonstration · Read Fable’s guide · Download the results

How often it happened

Four learners asked to predict paper layers, vary irrigation flow, repair a Python loop or get copper’s chemical symbol. Each prompt went to MiniMax M2.7 Highspeed and Gemini 3.1 Flash-Lite under each of three conditions. None of the four prompts asked for an interface by name. The irrigation learner explicitly declined a quiz. The guided conditions used the ordinary v2.3.3 web planning and release path. The unguided condition sent the ordinary tutor prompt and tools and returned its first response. Four requests to the Gemini tutor returned HTTP 503. All eight unguided calls returned. Among seven with a completed draft, five used an offered family on their first draft and four did so publicly. For Jev this changed from 3/3 to 2/3. For Gemini Decision it stayed 2/4. What a learner saw

In one fresh local classroom session a learner asked to vary a stage light’s flash rate over 12 seconds. Jev offered a Simulation. MiniMax wrote two drafts, and the second reached release after 24.123 seconds with an unverified best-effort notice. The browser mounted its slider alongside 47 words of prose. Moving from 6 to 7 flashes per second changed the count from 72 to 84. A second browser opened the saved reply and independently verified that 9 produced 108. When the learner answers in chat

The v2.3.6 review now checks two separate facts before treating an explanation as feedback. Did the learner answer the preceding question? Does the tutor accurately confirm or correct that answer using the facts in the question? The application retains both sets of probabilities on the private attempt. Strong evidence can make two generic checkpoint findings inapplicable. Independent findings about factual support, host actions, claims of mastery and other unanswered work continue to affect release.

We gave MiniMax the same original tile-bag Question and the same learner answer twice, each time with a single decision model handling planning and review. Both delivered correct feedback on that learner turn. Jev released its third private draft, a short confirmation of the 3/4 and 1/4 probabilities. Gemini Decision released the first draft, which gave the same probabilities, added two explanations and proposed an interactive page. The study recorded the proposal. Execution and rendering of that page remain unobserved. These two sessions supplied the recorded chat history and had no open-card record. Jev-guided reply · Gemini Decision-guided reply

We also sent each decision model four identical, predeclared review inputs and applied its actual response through Keating’s review logic. Both accepted the original correct feedback. Both rejected a false affirmation and a reply that revealed the answer to a new, unanswered Question. Both also rejected an accurate correction to a wrong guess. That gives each model three of four expected review outcomes. Jev had an independent uncertain preference check, and Gemini Decision had insufficient confidence in the correction. Both v2.3.5 first-turn controls worked, yet the passive observer classified both requests as having no cue. A dashboard using that classifier would have excluded two genuine opportunities from its denominator. The updated observer recognizes both. For a model or script, the read-only keating.openui_diagnostics WebMCP tool accepts {"view":"draft-loss","cue":"implicit-action","limit":5}. The CLI accepts the equivalent filters.

A Measure of Machine Judgement

Keating ships a 35 MB generative model called Needle to do three jobs: rank recall, extract a verbatim learner quote, and classify a topic into a subject. This is what each job scores against this repository's own corpora, what a static embedding model scores on the same rows, and what happened when a 0.8B decision model was pointed at the real captured judgement harness.

Execution shape

Every retrieval spawns a Python child, SHA-256s both assets, imports the runtime, constructs the model, and only then embeds. The default deadline is 12 seconds. On mobile the engine is process-global with no cancel and no unload: verified model bytes stay resident until the app exits.

The separation column is the robust signal

Recall at rank one depends on one threshold choice; whether the best relevant item outscores the best irrelevant one does not. Needle separates 7/11 literal and only 1/10 paraphrase queries: its embeddings sit in a narrow band where topical relevance barely moves the score. potion-base-8M separates 11/11 and 4/10.

Where the seconds go

A request carrying no real work still costs 209 ms: process spawn, a SHA-256 of both pinned assets, the runtime import, and model construction. That fixed cost is paid on every single call, with linear per-text cost on top.

An uncached recall embeds the query plus up to 128 source windows. At 4,785 ms for 128 texts that is most of the 12-second deadline, on a desktop CPU. The same workload through a static embedding model is 3.1 ms.

Measured twice

An earlier run on a more loaded machine recorded 337 ms fixed and 6,795 ms for 128 texts. The shape is stable across both runs; absolute numbers move with machine load, so treat them as a range.

A real defect, not a model limitation

Upstream needle.extract reads function_calls or suppressed_calls. Keating’s bridge in src/retrieval/needle-runtime.ts reads only function_calls, so all 8 suppressed decisions are discarded and the rung silently abstains. Suppression is triggered by the enum-shaped argument schema the bridge invents: with the empty-argument tool shape the model was actually trained on, calls emit normally.

Counting them would not rescue it

The suppressed picks include commerce clause → computing, bill become law → law, procrastinate → physics and Bayes → business, with reasoning such as “bill become law is a scientific field.” The plumbing bug hides a rung that was not working anyway.

Confidence can never gate this rung

needle.Needle(weights=...) sets _tuned whenever explicit weights are passed, and a tuned agent reports confidence: None by construction. Keating always passes explicit weights, so LOCAL_FIELD_CONFIDENCE_FLOOR = 0.7 can never fire — decideLocalModelField accepts null confidence as valid.

Verbatim extraction

04

This is the job the earlier write-up said Needle does well: given one learner message and a schema, return a category and a quote that is an exact substring of the input. Measured on 8 real learner messages with the production schema and strict=True.

Needle also raised ExtractionValidationError on two of the eight — grounding failures the bridge swallows. The alternative splits the message into spans and scores each against the five category rubrics, so the quote is a slice of the input and verbatim by construction rather than by post-hoc validation. Its weakness is the category head at 4/8 with small margins.

The index cost is the quiet win

A real on-disk index sample holds 1 entry of 3072 dimensions in 67,285 bytes of JSON for a 12,288-byte payload — 5.5× encoding overhead. At the 152-entry cap that projects to 10.2 MB, which is exactly why loadIndex carries a 12 MB ceiling. The same index at 256 dimensions packed as int8 is 38,912 bytes.

Refusal, and why a gate did not fix it

06

A static embedding model has no native way to refuse: it maps a string to a vector, and argmax always returns something. The honest way to abstain is a gate, so both were tried — a margin gate on top-two prototype separation, and an out-of-domain support gate on similarity to any known subject query. Thresholds were chosen on the labelled rows, then applied to the probe and six off-topic controls.

This one did not work, and that is the finding

With both gates open the tier answers all 170 rows and refuses 0/6 off-topic inputs. Every setting that refuses 5 or 6 controls also collapses coverage to a handful of rows. The support distributions overlap almost completely: labelled subjects span [0.168, 0.24, 0.306, 0.411, 0.692] across the 5th–95th percentile while the off-topic inputs sit at [0.107, 0.308, 0.353, 0.367, 0.452, 0.456]. There is no threshold between them, and the 8M model shows the same overlap.

So refusal is not solved by swapping the embedding model. It needs the separately calibrated gate shape already built for memory admission, or a model that emits a probability over an explicit none option.

One genuine positive

Of 90 disagreements, 0 were made at confidence ≥ 0.9. Its uncertainty honestly flags that it is out of its depth — the failure is visible rather than silent.

Why this is a shape mismatch as well as a limit

KEV’s own card reports out-of-domain accuracy 0.652 and warns that probabilities are advisory outside its training distribution. Its rows are short premise/hypothesis and classification items; a Keating rubric question is long prose criteria over a numbered multi-turn transcript. This data cannot separate “wrong” from “untrained for this shape”, which is the honest reason to want a fine-tune before calling the model unsuitable.

The packaging question, now resolved

The adapter and head are small — 65.4 MB including the tokenizer — but useless without the backbone, and Qwen/Qwen3.5-0.8B-Base ships 1746.9 MB of weights. Real deployment footprint is about 1.8 GB, roughly 50× the entire current Needle bundle. This is a server model.

The ceiling worth watching

33 rows were scored level 2 on every dimension. Roughly half the suite receives no discrimination at all. If these scores feed reward fitting or policy promotion, a ceiling that broad compresses the signal. Whether those candidates were genuinely excellent or the judge is lenient there is exactly what an incumbent comparison would settle, and that has not been run.

A minor inconsistency

13 of 60 stub evidence questions still cited a span rather than __no_match__. Citing the plumbing sentence as the span evidencing a zero is defensible, but it is not uniform.

The multilingual model breaks the constraint

potion-multilingual-128m-onnx is 547.0 MB at fp32 — 17.6× the 8M model — and its 34.6 MB tokenizer does not quantize. int8 lands near 130 MB plus tokenizer, still roughly 4× the entire current Needle bundle. Worth it only if learners actually write non-English text; its quality was never measured here.

The replacement needs zero new runtimes: static embeddings are a tokenizer plus a lookup table. That removes the embedded Python bridge, the venv, the WASM blob, the native C-ABI binding, and the ARM64-only device matrix — a typed-array path runs on iOS simulators and in Expo Go, which Needle explicitly cannot, and it can be freed on disable, which removes the “no cancel, no unload” caveat.

Jev stays

Nothing measured here argues for replacing the hosted judge. It answered every captured request with stable identity, sub-second, with abstention paths that fire only when evidence is genuinely absent. The local tier is the cheap rung beneath it, not a substitute for it.

Verification boundaries

10
  • Agreement is not correctness. Neither judge is ground truth on the captured rows, and this repository's own harness notes say so. No human review was performed.
  • No human-learning claim. Benchmarks over archived transcripts and synthetic learners do not establish mastery, retention, transfer or engagement. Those remain unknown.
  • Single machine, single platform. Everything ran on Linux x86-64 CPU. Nothing was measured on a phone, in a browser, or in the desktop app. KEV ran fp32 on CPU with no GPU present; its card assumes CUDA or MPS bf16, worth 2–4.5×.
  • KEV coverage is partial. 11 of 68 captured requests. The v3 and v4 states, 86–114 KB each, were not run through it.
  • The retrieval corpus is small and narrow. 90 messages, 21 queries, mostly software topics, median message length 34 characters. Directional, not definitive; the separation counts are the more robust signal.
  • potion ran through the Python library. A JS/TS port is small but unwritten and unmeasured, and no quality figure exists for the multilingual model.
  • Judgement calls are mine. The right/wrong labels on the eight extraction cases and the eight suppressed classifications are my assessment, not labelled data.

What this page is

A measurement record for the local models in Keating: what each one is wired into, what it scored on this repository's own corpora and captured harness, and where the evidence stops. Agreement between judges is agreement, not correctness. Benchmarks over archived transcripts are not evidence of human learning.

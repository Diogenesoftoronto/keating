## Keating: TUI, pi framework, Generative UI tools, and E2E testing

### 1. The TUI implementation

Keating has **two separate terminal UIs**, both launched from `src/cli/main.ts` (dispatch at lines ~501–513):

- **`keating shell` → the classic Pi TUI** (`launchShell`). This is the real, full-featured interface. It runs the hyperteacher extension in-process on top of `@earendil-works/pi-coding-agent` + `@earendil-works/pi-tui`. Interactive tool cards and `ctx.ui.custom` forms work here.
- **`keating tui` → the OpenTUI host** (`src/tui/opentui-host.ts`, `launchOpenTui`). Built on `@opentui/core` (`BoxRenderable`, `InputRenderable`, `ScrollBoxRenderable`, `TextRenderable`, `createCliRenderer`). It is a **thin RPC client** that talks to Pi over RPC (`launchRpcClient` from `src/runtime/pi.ts`).

State of the OpenTUI host: **partial / text-only**. It renders a header, a status line, a scrollable transcript, and an input box. It streams assistant `message_update`/`message_end` events as plain text. Critically, it does **not** render any interactive/generative UI. When an extension issues an `extension_ui_request` with method `select`/`confirm`/`input`/`editor`, it posts a notice ("This extension requested a Pi-specific input surface. Switch with /shell to use it.") and **cancels the request** (`sendUiResponse(id, { cancelled: true })`, opentui-host.ts lines 176–179). Typing `/shell` tears down OpenTUI and hands off to the classic Pi shell.

TUI-side rendering code (used by the classic Pi shell, not OpenTUI):
- `src/pi/hyper-teacher/tui-components.ts` — `renderCard`, `renderArtifactPreview`, `renderQuizCard`, `renderGoalCard`, `renderGoalListCard`, and the interactive `AnswerFormComponent` (keyboard-driven quiz form built from pi-tui `Input`/`SelectList`).
- `src/pi/hyper-teacher/header-component.ts`, `setup-wizard.ts`, `ui-helpers.ts`.

/**
 * Resolve a secret from the `skate` CLI (charmbracelet key-value store).
 * Names may target a db with the `key@db` form, e.g. "minimax@secrets".
 * Returns undefined when skate is missing, exits non-zero, or holds no value.
 */
export function resolveSkateSecret(name: string): string | undefined {
  try {
    const result = spawnSync("skate", ["get", name], { encoding: "utf8" });
    if (result.status !== 0) return undefined;
    const value = result.stdout.trim();
    return value.length > 0 ? value : undefined;
  } catch {
    return undefined;
  }
}

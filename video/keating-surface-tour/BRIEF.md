## Intent

A silent, fast tour for the Keating landing page. It shows the parts of the app
that are *not* the chat box. Every beat is a current Storybook capture of the
real component, taken by `video/shared/capture.mjs`. The captures are shown
unaltered, with only a gentle seek-safe pan and push.

## Feature arc

1. Simulate: the base-rate simulation, where moving a control redraws the chart.
2. Code: the TypeScript lab, where you write a solution and run the sample tests.
3. Speak: pronunciation practice, where you record and compare.
4. Recall: the flashcard arena with spaced review.
5. Exam: a timed exam you can flag and review.
6. Plan: a nested study plan with linked lessons.
7. Sessions: session search that keeps fork ancestry.
8. Desktop: a local workspace with real files and processes.

## Assets and provenance

- `shots.json` maps each beat to its Storybook story id.
- `assets/shots/*.png` are generated by `npm run capture`. They are gitignored,
  so recapture them after a clone or a UI change; add `FORCE=1` to overwrite.
  Set `STORYBOOK=<dir>` to reuse an existing static Storybook build.
- `assets/fonts/` is a copy of `video/shared/fonts`: Space Mono, JetBrains Mono
  and Roboto.
- The older footage in `assets/` (`web-classroom.mp4`, `tui-*.mp4`,
  `cli-artifacts.mp4`, `feature-*.jpg`) belongs to the previous cut and is no
  longer referenced.

## Rules

- Never restyle captured pixels. The composition adds only the frame, the
  rail, labels and camera motion.
- Use real Keating vocabulary and states. Don't invent users, quotes, figures
  or capabilities.
- Keep the stable scene ids (`#<name>-frame`), because `index.motion.json`
  asserts against them.
- Silent: no narration, music or sound effects. Hard cuts; the motion happens
  inside each 4 s beat.
